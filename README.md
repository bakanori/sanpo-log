# SANPO LOG — 散歩の地図

**歩いた町が、ぬられていく。**

バージョン **2.14.2**（2026.11.28）　→ [更新履歴](#更新履歴)

歩いた場所を、地図に残すための小さなウェブページです。

**ひらく：https://bakanori.github.io/sanpo-log/**

日本地図 → 都道府県 → 市区町村 → 町丁目 と、押すたびに地図が掘り下がっていきます。
行った場所には「行った」の印と、日付つきのメモを残せます。歩いた範囲はオレンジ色に染まっていきます。

## 使い方

記録は「散歩・メモ・タグ」の3つでできています。

- **メモ**：場所（町・市・県のどれか1つ）に付く一言。日付・時刻・位置・写真（リンクと、この端末にのこした写真）・タグを持てます
- **散歩**：同じ日のメモを自動でまとめたもの。タイトルと「まとめ」を書けます
- **タグ**：「#紅葉」のような目印。メモにも散歩にも付けられます

### はじめて開いたとき
- 日本地図と「いまいる町を、ぬる」だけが出ます。押すと、いまいる町まで近づいて、最初の町が塗られます（「地図から、えらぶ」で、自分で探してもOK）
- ほかのボタンは、最初の町が塗れてから出てきます

### スマホ（散歩中）
- **下のまん中の ＋ ここでメモ**：現在地の町まで自動でズームし、メモ欄が開きます
  - ひとことを書いて、となりの「のこす」。日付・時刻・位置は自動。`#紅葉` のように書けばタグになります
  - 上の1行で、**写真**（スマホの写真）・**日付：今日**（前の日の分は押して選ぶ。PCは欄がいつも出ています）・**場所：○○ ▾**（町 / 市 / 県 を選ぶ。「今日の鎌倉全体の感想」なら市。位置もここで）
  - **お店**：「場所 ▾」の中の「お店」から。お店の名前で「Googleマップで探す」→ Googleマップで「共有」→「コピー」→ 戻ると浮かぶ「コピーしたお店を、付ける」。住所や位置から町を自動で選び、メモに **お店の印** が付きます（押すと、そのお店を地図アプリで開く）。家で書いていても、お店の町に移って、家の位置ははずします
  - **写真 ▾** を押すと「スマホの写真を選ぶ」「Instagram・X のリンクを貼る」の2つから選べます。Instagram は投稿の「…」→「リンクをコピー」してから「リンクを貼る」（「Instagramを開く」から行って戻ると、ボタンが浮かびます）。ひとことの欄に貼っても入ります（Googleマップのリンクを貼ると、お店として入ります）。付けた写真は「写真 ▸ IG」の印で出て、× ではずせます
  - 「写真」でスマホの写真を選ぶと、アプリにのこします（全画面でもきれいな約800pxと、一覧用の約240px）。写真の中の位置情報は消えます
  - **写真は、その端末の中だけに置きます。** クラウドにも、グループにも送りません（スマホで入れた写真は、PCでは「べつの端末に」と出ます）
- **右下の ◎（いまの場所）**：現在地を地図に表示するだけ。となりの **⌂** で、日本地図にもどります（いつも出ています。日本地図を動かしたり拡大したあとに押すと、日本全体が見える位置にもどります）
- **さんぽ中** は、下に「さんぽ中」と ＋ だけが出ます
- **おかえりなさい**：散歩を「おわる」と（または、メモのある日の夕方に出る「おかえりなさい。今日をふりかえる」から）、**その日の散歩のページ**が開きます。いちばん上に「おかえりなさい・○町を歩きました・はじめての町」、地図では はじめての町が1つずつ光ります。そのまま「この日のことを書く」（名前をつける）、「この日に足す」（＋ 写真をまとめて・＋ お店・＋ 写真のリンク）、写真がまだならバックアップもできます
- スマホではホーム画面に追加しておくと、アプリのようにすぐ開けます
- **電波がなくても開けます**：アプリと、一度開いた地域の地図は端末にのこるので、山の中や地下でも開いて書けます（まだ開いたことのない地域は、電波のある所で一度開いておいてください）

### PC（家で整理）
- **ノート → 散歩**：散歩の一覧（月ごと）。「まだ書いていない日」で、「この日のこと」をまだ書いていない日だけ表示。書いた日は、その書き出しが一覧に出ます
- 散歩を開くと、その日のメモが時刻順に並び、地図には歩いた町が囲まれ、メモの位置が点線でつながります
  - 「この日のことを書く」で、その日の散歩をふりかえって書けます
  - 「▶ たどる」で、その日の道のりがメモの順に伸びていき、時刻も進みます（場所の分かるメモが2つ以上ある日）
- **ノート → 散歩** のいちばん上は「この1年」のカレンダーです。歩いた日がオレンジの点になり、押すとその日の散歩が開きます
- 各メモの **なおす** は、書くときと同じ並びです：上に **写真 ▾・日付・場所 ▾** の印（押すと、その中身が1つずつ開く）、下に ひとこと・くわしく・タグ。写真のリンクは × で外せる印になり、「スマホの写真を選ぶ」「Instagram・X のリンクを貼る」で足せます（スマホでは、保存とキャンセルがキーボードのすぐ上に出ます）。日付を変えると、その日の散歩に移ります
- **けす** と、すぐ消えて、下に「けしました ［もどす］」が5秒出ます（写真もいっしょに戻ります）。タグをはずす・道のりをけすも同じです
- **一覧からけす**：自分のメモの行は、スマホなら **左へすべらせる** と「けす」が出ます（最後まですべらせると、そのまま消えます）。PCは行にマウスを乗せると右はしに「けす」（メモの欄では なおす のとなり）。ノートの みんな・タグ、場所のページ、日のページのどこでも同じです。ほかの人のメモには出ません。グループに共有していたメモは、みんなの一覧からも消えます（もどせば戻ります）
- 各メモの **＋写真** で、あとから写真のリンクや写真を足せます。メモのどこかを押すと、地図がその場所へ動きます
- **ノート → タグ**：タグの一覧。タグを選ぶと、そのタグの場所が地図で囲まれ、メモと散歩が並びます
  - **名前を変える** で変更（既にあるタグ名にすると1つにまとまります）、**はずす** でタグだけ外せます
- 県や市を開いて名前の横の「＋ メモ」を押すと、その県・市へのメモと「この中のメモ」が見られます

### 共通
- **押す**：一段下の階層へ（都道府県 → 市区町村 → 町）　**ドラッグ**：移動　**ホイール／ピンチ**：拡大縮小
- **⌂（スマホは ◎ のとなり、PCは右下の「⌂ 日本」）**：日本地図にもどる。開いているノートやページも閉じます。PCは **Esc** で1つ上の階層へ
- **上の段は表示だけ**：県・市・町の数（歩いた数／ぜんぶ）と、町の名前の前に小さく県の名前。押せるのは、枠のついた **設定** だけです
- **ノート → 場所**：今の階層の一覧。歩いた場所が上に並び、まだの場所は「まだ歩いていない○○ ▾」にたたまれています（名前で絞り込み。「メモ」印は県・市そのものにメモがある場所）
- 下のボタンは、どの階層でも同じ（スマホ：**ノート・＋ ここでメモ・さんぽ** の3つと ◎ いまの場所、PC：ノート・設定）。**設定** はスマホは右上です
- **ページは1枚ずつ**：ノート・場所・散歩の日は、スマホは下から、PCは右に、同じところに1枚だけ出ます。ノートから場所を開くと、左上に **‹ ノート** が出て、押すと絞り込みもそのままのノートに戻れます（散歩の日から場所を開いたときは ‹ その日。PCは Esc でも戻れます）。× で閉じます
- **読む・書くを分ける**：メモがある場所では、まずメモが読めるように、書く欄は下の「＋ ここに、ひとこと」1本にたたまれています。押すと書く欄が開き、のこすと（または上の ⌄ で）またたたまれます
- **スマホ**：下から出てくる画面は、最初から画面の8割まで上がって、中身がよく見えます。上の部分を下に引くと半分ほどに下がって地図が見え、もう一度下に引くと閉じます（上に引くと8割に戻ります）。指についてきて、離すと、離した位置と速さで止まる場所が決まります。写真は左右にスワイプしても切り替わります
- **写真を見る**：メモの写真や「写真 ▸」を押すと、アプリの中で開きます（‹ › で次の写真、Esc や × で閉じる）。散歩や場所の「写真 ▸」で、その日・その場所の写真をまとめて見られます
  - Instagram と X は、それぞれ公式の「埋め込み」表示を使います。見られるのは**公開の投稿**だけです（Instagram は設定の「ウェブサイトへの埋め込み」がオンのもの）
  - 鍵をかけた投稿は、Instagram / X のきまりで、アプリの中には出せません（自分の投稿でも）。写真の画面の下の **Instagram で見る ↗ / X で見る ↗** で本家のアプリが開きます（スマホは左上の ◀ で戻れます）
  - となりの「アプリにのこす」でスマホから同じ写真を選ぶと、そのメモに付き、次からはアプリの中ですぐに出ます。鍵をかけたままで大丈夫です
  - ほかのサービス（Googleフォトなど）のリンクは、これまでどおり別の画面で開きます
- **道のり**：歩いた道を地図に点線でのこせます。2つの方法があります
  - **さんぽ、はじめる**（スマホ、下の段のいちばん右）：アプリを開いている間だけ記録します。電池をほとんど使わず、画面を消していた間はまっすぐの線でつなぎます。押すと「おわる／つづける」を選べます
  - **＋ 道のりを足す**（ノート → 散歩 のいちばん上。GPXファイルを読みこみます。PCではGPXファイルを画面にドロップしても）：記録アプリ（Stravaなど）で書き出したGPXを読みこみます。画面を消していても記録できるので、道をきっちりのこしたい日に
  - のこすときに「通った町を『行った』にする」を選べます。「▶ たどる」は実際の道のりに沿って進みます。道のりは散歩の「なおす」で消せます
  - **道の線は自分だけのもの**です。グループには出しません。ただし、その日にグループのタグ（例：`#散歩部`）を付けると、**通った町**（町の名前）と、日の名前・この日のことは、みんなにも見えます（日のページに「共有中」と出ます）
- **写真をまとめて入れる**（その日の散歩のページの「この日に足す」。ノート → 散歩 のいちばん上「＋ 日をえらんで足す」から、どの日のページも開けます）：散歩のあと、その日の写真をまとめて選ぶと、**撮った時刻にいちばん近いメモ**に振り分けます。確認の画面で、ちがうところだけ選びなおして「のこす」
  - 撮った場所が入っている写真（iPhoneは写真を選ぶ画面の「オプション」で位置情報をオン）は、同じ町のメモを優先し、近くにメモがなければ、その町に新しいメモを作れます。場所の情報は振り分けに使ったら消します
  - 撮った時刻が分からない写真（スクリーンショットなど）は、自分でメモを選びます。一度に40枚まで、1つのメモに8枚まで
- **お店をあとから足す**（その日の散歩のページの「この日に足す → ＋ お店」）：メモを書かなかった日でも、日付を選んで、お店の名前から Googleマップで探す →「共有」→「コピー」→「コピーしたお店を、付ける」で、その日のメモになります
  - コピーした文に住所があれば、その町に。スマホの短いリンクだけで町が分からないときは「どの町でしたか？」と、その日に歩いた町から選べます
  - PCでは、Googleマップのアドレス欄のURLを地図の上で ⌘V / Ctrl+V しても付きます（URLに位置が入っているので、町もピンも正確です）
  - 書いたメモにも、「なおす」の「お店」から付けられます。記録の検索は、お店の名前でも見つかります
- **写真のリンクを貼る**（その日の散歩のページの「この日に足す → ＋ 写真のリンク」。PCでは地図の上で ⌘V / Ctrl+V でも）：コピーした Instagram や X のリンクを、**投稿した時刻にいちばん近いメモ**に付けます
  - iPhone の「ショートカット」を使うと、Instagram や X の「共有」から直接送れます：新規ショートカット →「共有シートに表示」をオン（受け取るのは URL）→ アクション「URLを開く」に `https://bakanori.github.io/sanpo-log/?add=` と、その後ろに「ショートカットの入力」を入れる。Safari で開くので、ホーム画面のアプリと記録をそろえるには Google ログインが必要です

## スマホとPCの記録をそろえる（Googleでログイン）

1. スマホとPCのそれぞれで **設定**（スマホは右上、PCは右下）→ **Googleでログイン** を押す（同じGoogleアカウントで）
2. 以後は自動です。設定の点が緑（「同期しました」）なら同期済み

- 記録は Firebase（Google のクラウド、無料枠）の **あなた専用の場所** に保存され、ほかの人からは読めません
- **写真だけは、クラウドに送りません。** 入れた端末の中だけにあります（2.3.1 までにクラウドへ入った写真は、ログインしたときに端末へ移してから、クラウドから消します）
- 写真のバックアップは **設定 → バックアップ → バックアップする**（写真もいっしょに／小さくして／写真なし）。設定に、この端末の写真の枚数と、最後のバックアップの日、まだの写真の枚数が出ます
- 前のバックアップから1か月たって、まだの写真があると、アプリを開いたときに下に小さく「バックアップする／あとで」が出ます（散歩中や書いている途中は出ません。「あとで」なら1週間後にもう一度）
- ログインする前の記録も、ログインしたときにクラウドへ合流します（消えません）
- 片方の端末で消したメモは、もう片方からも消えます
- オフラインでもそのまま記録でき、つながったときに同期されます

## みんなで1枚の地図（グループ）

1. **設定 → みんなで** でグループ名を入れて「グループを作る」（2つ目からは「＋ 新しく作る」）
2. 「招待リンクを送る」で、LINEやメールでリンクを送る
3. 受け取った人はリンクを開いて「参加する」（Googleでのログインが必要）。**グループには5つまで入れます**（家族・散歩仲間など）。参加しても、今のグループはそのままです

**メモは基本「自分だけ」です。** グループに見えるのは、自分で選んだものだけ。

- **書くとき**：書く欄のいちばん下の **共有：自分だけ ／ 散歩部 ／ 家族** で選びます（2つ同時も可）。選んだものはその日1日だけ覚えていて、翌日は「自分だけ」に戻ります
- **あとから**：メモの「なおす」にも同じ **共有** の印があります
- **日ごと**：日のページの **この日を共有** で選ぶと、その日のメモ・この日のこと・通った町が、まとめてそのグループに見えます（道の線は出ません）
- しくみは、グループ名のタグ（例：`#散歩部`）です。共有を選ぶとタグが付き、外すとタグも外れます（タグを手で書いても同じです）
- 共有中のメモには「共有中」の印が付きます。書くときも、共有される場合は「のこす（みんなにも）」になり、ひとことの枠が自分の色になります

地図の見え方（上の切り替え **自分 ／ 散歩部 ／ 家族**）
- **自分**：自分の記録すべて（オレンジ）
- **グループ名**：そのグループだけに絞って、共有されたメモの町だけを、人ごとの色で（人の名前の横に「町○・メモ○」）（町は最初に歩いた人の色。同じ日なら先にメモを書いた人の色。2人以上が歩いた町は、その色を濃く。市や県はいちばん多く歩いた人の色）
- 町を開くと「ここを歩いた人」（色・名前・日付）と「みんなのメモ」、**ノート → みんな** でみんなの最近の共有メモと、共有された日（押すと、その日の名前・文章・通った町が読めます。道の線は出ません）

だれかが行った町に、自分も行ったとき
- 相手のメモの **「わたしも行った」** を押して、「○月○日に、いっしょに行った」か「別の日に行った」（日付を1つ選ぶ）
- 自分の記録として残り、グループにも出ます（相手のメモは書き換えません）。いっしょのときは、相手のメモに「いっしょ ● 名前」、自分のメモに「○○さんと、いっしょに」
- 取り消すときは、同じボタン（「わたしも行った ✓」）から

そのほか
- メモの正確な位置（GPS）と写真は、共有したメモでもグループには出しません（写真があるメモには「写真 ○ 枚は、本人の手もとに」と出ます。Instagram / X のリンクと、お店の名前・Googleマップのリンクは共有されます）
- 他の人のメモは見るだけで、直したり消したりはできません
- **設定 → みんなで** では、グループを印で選んで、人・表示名・招待・抜けるを扱います
- グループ名は作った人が 設定 で変えられます。変えると、みんなのタグも新しい名前に変わります（前の名前のタグも共有のまま）
- 抜けるのはいつでも 設定 から。抜けると自分の共有メモはグループから消えます（自分の記録はそのまま残ります）。作った人はメンバーを外すこともできます

## バックアップ

設定 の「バックアップ」→「バックアップする」で、記録と写真を1つのファイルにできます（スマホは「送る」で iPhone の「ファイル」や Google ドライブへ）。機種を変えたら、新しい端末で「バックアップから戻す」→ そのファイルを選ぶと、今ある記録に合流します（消えません）。

## 記録の形（第3版）

バックアップのファイルは、だれでも読める JSON です。このアプリがなくなっても、中身を取り出せるように、形をここに書いておきます。

- いちばん外：`app`（"sanpo-log"）、`v`（記録の形の版。今は 3）、`places`、`notes`、`walks`、`deleted`、写真を入れたときは `thumbs`（写真のid → JPEG の data URL）、`exported`（作った日時）
- 場所のキー：県は `p` ＋ 2けた（例 `p13`）、市区町村は `m` ＋ 5けたの全国地方公共団体コード（例 `m13106`）、町は `t` ＋ 5けた ＋ `_` ＋ 町の名前
- `places`：キー → `{ n: 名前, l: 県から書いた名前, v: 行った, ll: [経度, 緯度], u: 更新した時刻 }`
- `notes`：id → `{ id, k: 場所のキー, d: "YYYY-MM-DD", at: "HH:MM", t: ひとこと, x: くわしく, p: [写真のリンク], im: [写真のid], loc: [緯度, 経度, 誤差m], tags: [タグ], s: { n: お店の名前, a: 住所, u: 地図のリンク }, w: { u: だれのメモに, i: そのメモのid, n: その人の名前, y: 1 ならその日いっしょ }（「わたしも行った」のときだけ）, u }`
- `walks`：日付 → `{ d, title: 名前, sum: この日のこと, tags, trk: 道のり（座標を短い文字に詰めたもの）, km, t0, t1, tw: [通った町のキー], u }`
- `deleted`：`"n:<id>"` / `"w:<日付>"` → 消した時刻（ほかの端末から消えたものが戻らないように）
- 時刻（`u` など）は 1970年からのミリ秒。同じものが2つあるときは、`u` が新しい方を使います
- 版が上がっても、古い版の記録はそのまま読めます（第1版・第2版も読めます）

## GitHubで同期する（上級者向け・任意）

Googleでログインのかわりに、GitHubの非公開リポジトリ（例：`sanpo-data`）に `sanpo-log.json` として保存することもできます。
設定 →「GitHubと同期」に、そのリポジトリだけを対象にした合鍵（Fine-grained token、Contents：Read and write）を貼り付けて「接続する」。
合鍵はその端末のブラウザの中だけに保存され、GitHub以外には送りません。

## しくみ（このリポジトリについて）

- `index.html`：アプリの入口（画面の骨組みと、バージョン番号 `VERSION`）。部品はそれぞれ中身から作った名前（`?v=` のあとの10文字）で読みます。部品を変えたら、その `?v=` も変えます（公開前のテストが、名前と中身が合っているかを確かめます）
- `css/app.css`：見た目
- `js/`：アプリの本体を、役割ごとに8つのファイルに分けたもの。組み立ての作業はなく、ブラウザがこの順にそのまま読みます
  - `base.js` 土台（地図の計算・地図データの読みこみ） → `parts.js` 部品（タグの入力・写真の表示・ページを1枚ずつ・下のお知らせ） → `records.js` 記録（メモ・場所・散歩・写真の保存） → `sync.js` 同期（Google・GitHub・グループ） → `map.js` 地図（描く・動かす・指での操作） → `memo.js` メモ（書く・なおす・おかえり・お店） → `screens.js` 画面（いまの場所・ノート・日のページ・道のり・設定） → `start.js` 起動（いちばん最後）
  - 前のファイルで作ったものは、後のファイルからも使えます。開くときにすぐ動く部分は、自分より前のファイルのものだけを使います
- `sw.js`：電波がなくても開くための仕組み（入口の `index.html` はいつも新しいものを先に。部品は端末にのこし、名前が同じあいだは端末から読みます。地図のデータは端末にのこしたものを先に使います）
- `firebase-config.js`：Firebaseの接続設定（公開されて問題ない値です。データはセキュリティルールで本人だけに制限しています）
- `tests/smoke_test.py`：公開の前に自動で確かめるテスト（開く・書く・なおす・写真・お店・記録・バックアップ・電波なし・グループの「わたしも行った」・部品がそろっていて名前と中身が合っているか・一覧からけす・⌂ など56項目。グループは本物のクラウドを使わず `tests/fsmock.js` で確かめます）。1つでも落ちたら公開せず、前の版がそのまま残ります
- `tools/build_site.py`：地図データ（`data/`）とライブラリ（`lib/`）を公開データから作るスクリプト
- `.github/workflows/pages.yml`：`main` に変更が入るたびに、上のスクリプトでサイトを組み立てて GitHub Pages に公開します

## 軽さのための工夫

- アプリの本体（見た目と動き、約340KB）は役割ごとの部品に分け、中身から作った名前を付けて端末にのこします。版が上がったときは、変わった部品だけを新しく読みます（入口の `index.html` は約17KB）。
- ライブラリは町丁目の区切り計算用の d3-delaunay（約20KB）だけ。町を開いたときにだけ読み込みます。
- 同期用の Firebase は、ログインするときにだけ読み込みます。
- 地図データは都道府県ごとに分割し、開いた県・市の分だけ読み込みます（最初に読むのは日本全図の約60KB）。
- 地図はすべてSVGで描いています。背景地図のタイル画像などは使っていません。
- 写真は投稿へのリンクと、アプリにのこした写真（約800pxと約240pxの2枚、合わせて100KBほど）だけを持ちます。写真はメモとは別の場所（その端末の IndexedDB）だけに置き、クラウドの無料枠はメモの文字だけに使います。一覧には小さな写しを使い、大きいほうは開いたときだけ読みます。
- 写真の表示は、押したときにだけ Instagram / X の埋め込みページを読み込み、閉じると捨てます。各社のスクリプト（embed.js・widgets.js）も使いません。
