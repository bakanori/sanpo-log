# SANPO LOG — 散歩の地図

**歩いた町が、ぬられていく。**

バージョン **2.3.0**（2026.11.22）　→ [更新履歴](#更新履歴)

歩いた場所を、地図に残すための小さなウェブページです。

**ひらく：https://bakanori.github.io/sanpo-log/**

日本地図 → 都道府県 → 市区町村 → 町丁目 と、押すたびに地図が掘り下がっていきます。
行った場所には「行った」の印と、日付つきのメモを残せます。歩いた範囲はオレンジ色に染まっていきます。

## 使い方

記録は「散歩・メモ・タグ」の3つでできています。

- **メモ**：場所（町・市・県のどれか1つ）に付く一言。日付・時刻・位置・写真（リンクと小さな写真）・タグを持てます
- **散歩**：同じ日のメモを自動でまとめたもの。タイトルと「まとめ」を書けます
- **タグ**：「#紅葉」のような目印。メモにも散歩にも付けられます

### スマホ（散歩中）
- **右下の ＋（ここでメモ）**：現在地の町まで自動でズームし、メモ欄が開きます
  - 「記録先」で **町 / 市 / 県** を選べます（「今日の鎌倉全体の感想」なら市を選ぶ）
  - ひとことメモを書いて「のこす」。日付・時刻・位置は自動。前の日の分は「◷ 今日」を押すと日付と時刻を選べます（PCは欄がいつも出ています）。`#紅葉` のように書けばタグになります
  - 写真は Instagram や X に投稿して「リンクをコピー」→「貼る」。ひとことの欄にリンクをそのまま貼っても、写真のリンクとして入ります
  - 「◫ 写真」でスマホの写真を選ぶと、小さく（約240px・10KBほど）してアプリにのこします。写真の中の位置情報は消えます
- **◎ HERE**：現在地を地図に表示するだけ
- スマホではホーム画面に追加しておくと、アプリのようにすぐ開けます

### PC（家で整理）
- **LOG → WALKS**：散歩の一覧（月ごと）。「メモだけの日」で、まだくわしく書いていない日だけ表示
- 散歩を開くと、その日のメモが時刻順に並び、地図には歩いた町が囲まれ、メモの位置が点線でつながります
  - 「＋ タイトルとまとめを書く」で、その日の散歩をふりかえって書けます
  - 「▶ たどる」で、その日の道のりがメモの順に伸びていき、時刻も進みます（場所の分かるメモが2つ以上ある日）
- **LOG → WALKS** のいちばん上は「この1年」のカレンダーです。歩いた日がオレンジの点になり、押すとその日の散歩が開きます
- 各メモの **なおす** で、日付・時刻・くわしい文章・タグ・写真・記録先（町/市/県）を直せます。日付を変えると、その日の散歩に移ります。メモをけすのも、この画面の中です
- 各メモの **＋写真** で、あとから写真のリンクや写真を足せます。メモのどこかを押すと、地図がその場所へ動きます
- **LOG → TAGS**：タグの一覧。タグを選ぶと、そのタグの場所が地図で囲まれ、メモと散歩が並びます
  - **名前を変える** で変更（既にあるタグ名にすると1つにまとまります）、**はずす** でタグだけ外せます
- 県や市を開いて名前の横の「MEMO」を押すと、その県・市へのメモと「この中のメモ」が見られます

### 共通
- **押す**：一段下の階層へ（都道府県 → 市区町村 → 町）　**ドラッグ**：移動　**ホイール／ピンチ**：拡大縮小
- **Esc / ↑ UP / 上のパンくず**：上の階層へ
- **LIST**：今の階層の一覧（名前で絞り込み。MEMO印は県・市そのものにメモがある場所）
- **読む・書くを分ける**：メモがある場所では、まずメモが読めるように、書く欄は下の「＋ ここに、ひとこと」1本にたたまれています。押すと書く欄が開き、のこすと（または上の ⌄ で）またたたまれます
- **スマホ**：下から出てくる画面は、上の部分を上に引くと大きく、下に引くと元に戻り、もう一度下に引くと閉じます。写真は左右にスワイプしても切り替わります
- **写真を見る**：メモの写真や「写真 ▸」を押すと、アプリの中で開きます（‹ › で次の写真、Esc や × で閉じる）。散歩や場所の「写真 ▸」で、その日・その場所の写真をまとめて見られます
  - Instagram と X は、それぞれ公式の「埋め込み」表示を使います。見られるのは**公開の投稿**だけです（Instagram は設定の「ウェブサイトへの埋め込み」がオンのもの）
  - 鍵のかかった投稿は、右上の INSTAGRAM ↗ / X ↗ から本家のアプリで開けます。アプリの中でも見たい写真は「◫ 写真」で小さな写真としてのこしてください
  - ほかのサービス（Googleフォトなど）のリンクは、これまでどおり別の画面で開きます
- **道のり**：歩いた道を地図に点線でのこせます。2つの方法があります
  - **さんぽ、はじめる**（スマホ、右下の ＋ のとなり）：アプリを開いている間だけ記録します。電池をほとんど使わず、画面を消していた間はまっすぐの線でつなぎます。押すと「おわる／つづける」を選べます
  - **＋ 道のり（GPX）**（LOG → WALKS のいちばん上。PCではGPXファイルを画面にドロップしても）：記録アプリ（Stravaなど）で書き出したGPXを読みこみます。画面を消していても記録できるので、道をきっちりのこしたい日に
  - のこすときに「通った町を『行った』にする」を選べます。「▶ たどる」は実際の道のりに沿って進みます。道のりは散歩の「なおす」で消せます
  - **道のりは自分だけのもの**です。グループには出しません（家の場所が分かってしまうため）
- **写真のリンクを貼る**（LOG → WALKS のいちばん上。PCでは地図の上で ⌘V / Ctrl+V でも）：コピーした Instagram や X のリンクを、**投稿した時刻にいちばん近いメモ**に付けます
  - iPhone の「ショートカット」を使うと、Instagram や X の「共有」から直接送れます：新規ショートカット →「共有シートに表示」をオン（受け取るのは URL）→ アクション「URLを開く」に `https://bakanori.github.io/sanpo-log/?add=` と、その後ろに「ショートカットの入力」を入れる。Safari で開くので、ホーム画面のアプリと記録をそろえるには Google ログインが必要です

## スマホとPCの記録をそろえる（Googleでログイン）

1. スマホとPCのそれぞれで **DATA**（スマホは右上、PCは右下）→ **Googleでログイン** を押す（同じGoogleアカウントで）
2. 以後は自動です。右上が `SYNCED · CLOUD` なら同期済み

- 記録は Firebase（Google のクラウド、無料枠）の **あなた専用の場所** に保存され、ほかの人からは読めません
- ログインする前の記録も、ログインしたときにクラウドへ合流します（消えません）
- 片方の端末で消したメモは、もう片方からも消えます
- オフラインでもそのまま記録でき、つながったときに同期されます

## みんなで1枚の地図（グループ）

1. **DATA → みんなで** でグループ名を入れて「グループを作る」
2. 「招待リンクを送る」で、LINEやメールでリンクを送る
3. 受け取った人はリンクを開いて「参加する」（Googleでのログインが必要）

**メモは基本「自分だけ」です。** グループに出すのは、グループ名のタグ（例：`#散歩部`）を付けたものだけ。

- メモ欄の「自分だけ（押すと #散歩部 で共有）」を押すと、その日のメモはタグ付きで共有されます（翌日になると「自分だけ」に戻ります）
- あとから共有したいメモは、編集でタグに `#散歩部` を足すだけ。外せば共有をやめられます
- 散歩（1日）のタグに `#散歩部` を付けると、その日のメモがまとめて共有されます
- 共有中のメモには「共有中」の印が付きます

地図の見え方
- **ME**：自分の記録すべて（オレンジ）
- **グループ名**：共有されたメモの町だけを、人ごとの色で（町は最初に歩いた人の色、市や県はいちばん多く歩いた人の色）
- 町を開くと「ここを歩いた人」と「みんなのメモ」、**LOG → GROUP** でみんなの最近の共有メモ

そのほか
- メモの正確な位置（GPS）は、共有したメモでもグループには出しません
- 他の人のメモは見るだけで、直したり消したりはできません
- グループ名は作った人が DATA で変えられます。変えると、みんなのタグも新しい名前に変わります（前の名前のタグも共有のまま）
- 抜けるのはいつでも DATA から。抜けると自分の共有メモはグループから消えます（自分の記録はそのまま残ります）。作った人はメンバーを外すこともできます

## バックアップ

DATA の「もしものとき」→「ファイルに保存」で、記録をファイルに書き出せます。別の端末で「ファイルを選ぶ」と、今ある記録に合流します。
ときどき書き出しておくと安心です。

## GitHubで同期する（上級者向け・任意）

Googleでログインのかわりに、GitHubの非公開リポジトリ（例：`sanpo-data`）に `sanpo-log.json` として保存することもできます。
DATA →「GitHubと同期」に、そのリポジトリだけを対象にした合鍵（Fine-grained token、Contents：Read and write）を貼り付けて「接続する」。
合鍵はその端末のブラウザの中だけに保存され、GitHub以外には送りません。

## しくみ（このリポジトリについて）

- `index.html`：アプリ本体（1ファイル）
- `firebase-config.js`：Firebaseの接続設定（公開されて問題ない値です。データはセキュリティルールで本人だけに制限しています）
- `tools/build_site.py`：地図データ（`data/`）とライブラリ（`lib/`）を公開データから作るスクリプト
- `.github/workflows/pages.yml`：`main` に変更が入るたびに、上のスクリプトでサイトを組み立てて GitHub Pages に公開します

## 軽さのための工夫

- ライブラリは町丁目の区切り計算用の d3-delaunay（約20KB）だけ。町を開いたときにだけ読み込みます。
- 同期用の Firebase は、ログインするときにだけ読み込みます。
- 地図データは都道府県ごとに分割し、開いた県・市の分だけ読み込みます（最初に読むのは日本全図の約60KB）。
- 地図はすべてSVGで描いています。背景地図のタイル画像などは使っていません。
- 写真は投稿へのリンクと、約240pxの小さな写真だけを持つので、記録は軽いままです（1000枚でも10MBほど）。小さな写真はメモとは別の場所（IndexedDB）に置き、メモの一覧は軽いままにしています。
- 写真の表示は、押したときにだけ Instagram / X の埋め込みページを読み込み、閉じると捨てます。各社のスクリプト（embed.js・widgets.js）も使いません。

## データの出典・ライセンス

- 市区町村・都道府県の境界：「国土数値情報（行政区域データ）」（国土交通省）を加工して作成
  （簡素化データは [smartnews-smri/japan-topography](https://github.com/smartnews-smri/japan-topography) を利用）
- 町丁目の代表点：[Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)（CC BY 4.0）を加工して作成
  （元データ：国土交通省 位置参照情報）
- 町丁目の範囲は、代表点からボロノイ分割で推定したおおよその範囲です。実際の町境とは異なります。
- 市区町村の境界は2021年1月時点のものです。
